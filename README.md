# Orange Import VAT to PEAK

เว็บ Streamlit สำหรับอัปโหลด PDF ใบรับสินค้า แล้วแตกเป็นรายการสินค้าเพื่อสร้างไฟล์ Excel/CSV สำหรับนำเข้า PEAK ตาม template จริง

## วิธีใช้

1. เปิดเว็บแอป
2. ตั้งค่าข้อมูลเอกสารใน sidebar เช่น วันที่เอกสาร, อ้างอิงถึง, คู่ค้า, เลขที่ใบกำกับฯ
3. อัปโหลด PDF ใบรับสินค้าได้หลายไฟล์ เช่น `1386.pdf`, `1388.pdf`
4. ถ้ามีไฟล์ Excel PEAK เดิม ให้อัปโหลดเพิ่มเพื่อใช้เป็น master ราคา/คำอธิบายสินค้า
5. ตรวจตารางรายการสินค้าและแก้จำนวน/ราคา/คำอธิบายได้ทันที
6. ดาวน์โหลดไฟล์ Excel หรือ CSV สำหรับนำเข้า PEAK

## วิธี Deploy บน Streamlit Cloud

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub
3. ไปที่ Streamlit Cloud
4. เลือก `Deploy a public app from GitHub`
5. เลือก repository ที่อัปโหลด
6. ช่อง main file path ใส่ `app.py`
7. กด Deploy

## หมายเหตุ

- แอปอ่านตัวอย่าง `1386.pdf` ได้ 17 รายการ และ `1388.pdf` ได้ 9 รายการ
- ถ้า PDF เป็นสแกนรูป แอปจะพยายามใช้ OCR ผ่าน Tesseract
- ควรตรวจข้อมูลในตารางก่อน export ทุกครั้ง เพราะ PDF/OCR อาจอ่านตัวเลขคลาดเคลื่อนได้
- ถ้าอัปโหลดไฟล์ PEAK เดิม แอปจะดึงราคา บัญชี คำอธิบาย และกลุ่มจัดประเภทจากไฟล์นั้นมาใช้
